# Academic & Engineering Projects Portfolio

This repository contains key academic projects demonstrating my background in algorithm design, statistical modeling, data engineering, and complex system implementation.

---

## Project 1: Intelligent Path Planning System for Unmanned Vessels
* **Institution / Context**: Shanghai Jiao Tong University
* **Tech Stack**: Python, GeoPandas, Matplotlib, Custom Graph Search Algorithms
* **Key Achievements**:
  * Modeled complex maritime domains using state-space discretization and grid-based representation.
  * Implemented pathfinding algorithms including $A^*$, Dijkstra, Depth-First Search (DFS), and Breadth-First Search (BFS) for optimal navigation.
  * Processed geospatial datasets using `GeoPandas` for coordinate transformation and spatial analysis.
  * Constructed state transition matrices considering transition costs to support real-time decision-making.

## Project 2: Dynamic Fault Diagnosis System for Industrial Machinery
* **Tech Stack**: B-Prolog, Logic Programming, Dynamic Memory Predicates
* **Key Achievements**:
  * Engineered a forward-chaining expert system in B-Prolog for real-time rotating machinery fault diagnosis.
  * Designed short-term and long-term memory architectures to dynamically maintain diagnostic states.
  * Implemented dynamic predicate manipulation (`assert`/`retract`) for real-time rule-based inference under changing operational constraints.
